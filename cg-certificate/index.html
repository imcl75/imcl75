Celebration Gathering certificates

Assign children to weeks, then download that week's certificates as a PowerPoint.

1 · Generate

2 · Schedule

Each child sits in a week. “No gathering this week” moves that week and every later week along by one, skipping holidays because only school weeks are in the list. Everything is editable in place.

3 · Add a list of children

One child per line: Week, Name, Reason separated by a tab (paste straight from a spreadsheet) or by |. For example T1W3 | Ada Lovelace | her perseverance in maths…. Write the reason as the words that come after “…today because”.

Backup and template

Names live only in this browser — never on the website itself. “Save automatically to a folder…” (at the top of the page) asks Chrome or Edge to remember a folder on your Mac, such as your CG HCF folder in OneDrive, and from then on writes CG certificates backup.json there every time something changes — no further clicking needed, and OneDrive keeps its own older versions of that file if you ever need to go back. It only works in Chrome or Edge; Safari can't do this, so use Export/Import there instead. The certificate design is master.pptx next to this page; replace that file to change the design. It looks for the text “Child Name”, “Hazel”, “T1W3”, the “Celebration Gathering today because […]” sentence and the signature line.
