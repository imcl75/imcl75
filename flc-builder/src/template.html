Getting started

1. Class — open the Tracker CSV and pick your class (names and Reading, Writing, Maths DOOYA).
2. Attendance — open the attendance spreadsheet (attendance % and lates).
3. Pupil voice — open the Microsoft Forms results; comments are matched to children and tidied.
4. Suggest targets — fills every blank target from the bank, matched to each child's DOOYA. Change any you want.
5. Print / save PDF — one A4 page per child, in the usual FLC layout.
Every step takes a file (Excel .xlsx or .csv) or a paste from Excel.

Everything stays on this computer. Nothing is sent anywhere.

Target bank

Targets are grouped by subject and tagged with the DOOYA bands they suit: D greater depth, O on track, Y yet to be on track, A earlier stage. Targets marked Nov 2024 are the ones you used last time. Add your own below — they are saved on this computer and offered first.

Tidy with Claude (automatic)

Sends the children's comments to Claude and puts the tidied versions straight into each child's page. Only the comments are sent, each labelled with a code (P01, P02…). Names, grades and attendance are never sent. Spelling, grammar and punctuation are corrected, small missing words are added, and short answers become full sentences — the children's own words and ideas are kept.

Other ways to tidy

Two ways to tidy children's comments. Both keep their words and meaning — only spelling, grammar and punctuation change. You always see the original next to the tidied version, and you can edit either.

Option A — quick tidy (built in, instant)

Fixes capital letters, “i” and “l” for “I”, spelling (about 150 common mistakes), full stops between run-together sentences, and small missing words — e.g. “…my handwriting so I will practise”, “I want to improve”, “it's fun”, “our experiment”. Always check the highlighted changes; very tangled comments are better tidied with Claude.

Option B — copy and paste through a Claude chat (no API key needed)

Copies all comments with a code for each child (P01, P02…) and no names. Paste into Claude, then paste the reply back here.

Save and open

Your work saves automatically in this browser on this computer. To keep a copy (or move to another computer), save a file. Keep it somewhere secure — it contains children's names and comments.

Export to the old spreadsheet

Copies a table in the same column order as the Data tab of the FLC Excel template (ID, First Name, Last Name, R, W, M, Attendance, Lates, targets, pupil voice). Paste into cell B3 of the Data tab.

Finished?

Clears all pupils, comments and targets from this browser. Your own bank targets are kept.

Add class data

Tracker CSV: open the file — pick your class and the Reading, Writing and Maths DOOYA are read in (O1 and O2 both show as O). The Tracker has no attendance, so paste attendance and lates afterwards (Name, Attendance, Lates) — existing children are updated, nothing else changes.
Anything else: copy from Excel and paste below. Include a header row if you can — the tool looks for columns called Name (or First Name + Last Name), R, W, M, Attendance and Lates. With no header row it reads: Name, R, W, M, Attendance %, Lates.
DOOYA can be D, GD, O, Y, A, or “A Y3” for an earlier year group.

Add pupil voice

In Microsoft Forms choose Open results in Excel. Click any cell, press Ctrl+A then Ctrl+C (⌘A, ⌘C on a Mac) and paste the whole sheet below. The tool finds the column with the children's names (it ignores Forms' own “Name”/“Email” columns when they just say None or anonymous) and joins the answers in order. Short answers are turned into sentences that fit the question — e.g. “Handwriting so I will practise” → “I would like to improve my handwriting so I will practise.” Names typed in capitals, first names only and small spelling slips are matched; anything unsure is listed for you to choose.

Add attendance and lates

Open the attendance spreadsheet (.xlsx or .csv) or paste it from Excel. The tool finds the columns for the child's name, attendance % and number of lates, and matches names to your class. Only your class is updated — other children in the file are ignored. Title rows above the table are fine.
