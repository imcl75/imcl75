FLC Builder

Getting started

1. Add class data — paste names, DOOYA (R, W, M), attendance % and lates from your spreadsheet.
2. Add pupil voice — paste the Microsoft Forms results, then tidy them.
3. Suggest targets — fills every blank target from the bank, matched to each child's DOOYA. Change any you want.
4. Print / save PDF — one A4 page per child, in the usual FLC layout.

Everything stays on this computer. Nothing is sent anywhere.

Target bank

Targets are grouped by subject and tagged with the DOOYA bands they suit: D greater depth, O on track, Y yet to be on track, A earlier stage. Targets marked Nov 2024 are the ones you used last time. Add your own below — they are saved on this computer and offered first.

Tidy pupil voice

Two ways to tidy children's comments. Both keep their words and meaning — only spelling, grammar and punctuation change. You always see the original next to the tidied version, and you can edit either.

Option A — quick tidy (built in, instant)

Fixes capital letters, “i” and “l” for “I”, spelling (about 150 common mistakes), full stops between run-together sentences, and small missing words — e.g. “…my handwriting so I will practise”, “I want to improve”, “it's fun”, “our experiment”. Always check the highlighted changes; very tangled comments are better tidied with Claude.

Option B — tidy with Claude (better for run-on sentences)

Copies all comments with a code for each child (P01, P02…) and no names. Paste into Claude, then paste the reply back here.

Save and open

Your work saves automatically in this browser on this computer. To keep a copy (or move to another computer), save a file. Keep it somewhere secure — it contains children's names and comments.

Export to the old spreadsheet

Copies a table in the same column order as the Data tab of the FLC Excel template (ID, First Name, Last Name, R, W, M, Attendance, Lates, targets, pupil voice). Paste into cell B3 of the Data tab.

Finished?

Clears all pupils, comments and targets from this browser. Your own bank targets are kept.

Add class data

Copy from Excel and paste below. Include a header row if you can — the tool looks for columns called Name (or First Name + Last Name), R, W, M, Attendance and Lates. With no header row it reads: Name, R, W, M, Attendance %, Lates.
DOOYA can be D, GD, O, Y, A, or “A Y3” for an earlier year group.

Add pupil voice

Open the Microsoft Forms results in Excel. Copy the Name column and the answer column(s) — with the header row — and paste below. If there are several answer columns (e.g. enjoyed / improve / how), they are joined into one comment in that order.

Paste Claude's reply

Paste the whole reply. Lines that start with a code (P01:, P02:…) are matched to children. The original comment is kept so you can compare.
